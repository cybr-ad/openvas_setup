# openvas_setup
It will setup OpenVAS completely in your Debian system. Sometimes running basic commands may face some error , that's why this script will automate and setup your OpenVAS. Before running this script make sure you have at least 30 GB storage is free to run it smoothly.  Default , user=admin , passwd=admin . 


# openvas_remove
If you completely remove the OpenVAS then run "./openvas_remove.sh" script.
then "reboot"
after reboot run "sudo apt update && sudo apt full-upgrade -y"
